Συγχρονισμός GitHub & αντίγραφα

Το token μένει αποθηκευμένο μόνο στον browser της συσκευής σου (δεν δημοσιεύεται ποτέ στο GitHub). Χρειάζεται token με δικαιώματα repo (ή fine-grained: Contents: Read and write).
Οδηγίες: δημοσίευση online και συγχρονισμός από παντού
  1. Δημιουργία αποθήκετυπου: στο GitHub → New repository (π.χ. varei) → Public (για δωρεάν GitHub Pages) ή Private (τότε η φόρτωση χρειάζεται token).
  2. Ανέβασμα αρχείων: ανέβασε το index.html και το weights.json στη ρίζα του repo (Upload files).
  3. Ενεργοποίηση site: Settings → Pages → Source: Deploy from a branch → branch main / root → Save. Σε λίγα λεπτά το site είναι στο https://CHORTHSEOS-USERNAME.github.io/varei/
  4. Token: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate (Repository permissions: Contents = Read and write). Άντιγρψέ το στο πεδίο «GitHub Token» της εφαρμογής και πάτα «Αποθήκευση στο GitHub».
  5. Καθημερινή χρήση: μπαίνεις στο site από οπουδήποτε, καταχωρείς τα βάρη, πατάς «Αποθήκευση στο GitHub» (ή ενεργοποιείς την αυτόματη αποθήκευση) και τα δεδομένα φαίνονται σε όλες τις συσκευές.
  6. Χωρίς internet / εναλλακτική: τα δεδομένα μένουν πάντα και στον browser της συσκευής + μπορείς να κάνεις εξαγωγή/εισαγωγή JSON αρχείο.
