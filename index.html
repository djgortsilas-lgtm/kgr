Σύνδεση με GitHub

Κάθε αλλαγή αποθηκεύεται αυτόματα στο github.com/djgortsilas-lgtm/kgr. Χρειάζεται μόνο ένα token πρόσβασης.

Δημιουργία token: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Repository kgr → Permissions: Contents Read and write. Το token μένει μόνο στον browser αυτής της συσκευής και δεν δημοσιεύεται ποτέ.
